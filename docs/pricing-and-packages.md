FEMA flood + access read · **shareable interactive viewer** (the differentiator vs a PDF) · under 72hr.

a written qualitative buildable/slope/drainage/access read.

### ⭐ The subscription upside (Acres-style — "a different group")
The **Desktop Report** is the seed of a **land-intelligence subscription/SaaS** (à la Acres) for a
different buyer set — investors/land pros who screen many parcels. Same engine (parcel + 3DEP + FEMA +
viewer), productized as **self-serve, recurring**, national, zero-flight = pure software margin. Build
the Desktop deliverable rock-solid first (per-report), then wrap it as a subscription. This is the
scalable long game; the flown work funds and validates it. (See platform §13 P4.)

## Roof / inspection — content + opportunistic lane (NOT a headline SKU yet)
More prevalent than assumed (~4 drones on the rental's remodel + roof job; insurers/inspectors do
fences, surveying, completion inspections). **Play now:** make the CONTENT (gutter / solar / roof
inspection demos); pitch roofers & inspectors the **"5-min flight to QC your crew's work"** + the
**"liability lock-in video."** Visual condition only, never survey-grade. **Thermal drone = buy it
WHEN the jobs justify it** (spend-then-to-close; unlocks premium roof/solar/energy/insurance buyers).

## Do NOT offer
- Progress-mapping **retainers** right now (solo + relocating can't guarantee revisits; no RTK = no
  volumetrics). Defer to Phase-2 post-Omaha; if asked, sell VISUAL documentation only.
- Anything **hourly / "contact for a quote"** on entry products.
- Any **survey-grade / boundary / measurement** claim — liability + unlicensed-practice landmine.

## Positioning (the intelligence lane)
Sell it as **pre-purchase / pre-design DECISION intelligence** and **pre-survey feasibility
screening** — a fast, cheap first look BEFORE (and to scope down) a stamped survey, never a
substitute. Three non-negotiables on every intel deliverable:
1. Written **"screening-grade, NOT a boundary survey, ~1–3m, QUALITATIVE"** disclaimer; never a
   sq-ft/slope-% a client designs to (unlicensed surveying — TX TBPELS + NE enforce).
2. Be transparent: terrain = free **USGS 3DEP**, parcels = **county GIS**. The moat is **synthesis +
   judgment + fresh aerials + the interactive viewer + turnaround**, not proprietary data.
3. The **shareable interactive viewer** (a link the buyer forwards to architect + lender) is the one
   thing no commodity stills-shooter can copy. Lean on it hard.
